# Football Shot Map Analysis

A match-level football analytics project using StatsBomb Open Data to investigate where a team takes its shots and what outcomes those shots produce.

## Project Objective

To analyze the spatial distribution of shots and their outcomes within a selected football match, translating event data into visual insights that support match analysis.

## Current Progress

- Shot map visualization implemented in Python.
- Spatial analysis of shot locations and shot outcomes.
- Analytical notebook under development.
- Reproducibility and documentation improvements in progress.

## Data Source

StatsBomb Open Data. See the official [StatsBomb Open Data repository](https://github.com/statsbomb/open-data) for the source data and its terms of use.

## Status

Work in progress. Findings currently describe an individual match and should not be interpreted as general team tendencies.
